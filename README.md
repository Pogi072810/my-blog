# Group 2: Tax Decoded

Performance Task 1 General Mathematics by Group 2 of Mobius. A simple sci-fi guide to Philippine taxation and piecewise functions. A full-screen question—“Earn more. Pay how much?”—links directly to the tax calculation and graph. The main content uses open layouts and short explanations; extra notes expand when needed.

## Open locally

Open `index.htm` in a browser, or run:

```sh
python3 -m http.server 3000 --bind 0.0.0.0
```

Visit `http://localhost:3000/index.htm`. The entry is `index.htm` because the repository already contains a directory named `index.html`. Original class exercises are preserved.

The HTML contains all CSS, JavaScript, SVG graphics, and fonts. Atkinson Hyperlegible makes body text easier to read, Space Grotesk sets the headings, and IBM Plex Mono displays equations. All fonts are embedded with their SIL Open Font License notices; no packages or asset downloads are required. Larger type, generous spacing, and subtle graph, balance-scale, and receipt illustrations support the sci-fi lesson. It works offline; legal reference links open external pages only when clicked.

## Using the guide

- Click **Explore Philippine taxes** to move from the full-screen introduction to the mathematics.
- Select a tax type and enter an amount, move the slider, or drag the graph. Arrow keys, Home, and End work on the graph. Keyboard users can also change model tabs with arrow keys.
- Inspect the equation and sample table below the graph. The applicable formula is highlighted. Open **Conditions & assumptions** for model qualifications.
- Load a worked example using the example links under the model tabs.
- Read the brief fairness discussion. Expand **Compare two incomes** for an interactive TRAIN-versus-hypothetical-flat-tax comparison.
- Expand the exemption notes or other-tax notes when needed.

Inputs, opinions, and written reflections exist only in the current page. Reload to reset; no data is collected or stored remotely.

## Scope

The personal tax model uses TRAIN rates effective from 2023. The 8% model assumes an eligible, purely self-employed taxpayer electing that regime, with a ₱3 million upper limit. Corporate calculations cover regular CIT, excluding MCIT and special incentives. VAT and capital-gains models use distinct taxable bases, not personal income brackets. Full qualifications and primary legal sources are included in the page.
